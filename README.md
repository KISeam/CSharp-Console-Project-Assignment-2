# C-Console-Project-Assignment-2

A simple C# console application developed using .NET 10.0.  
This project demonstrates basic variable handling, console output, and fundamental C# programming concepts.

---

## 📌 Project Overview

The application prints product information to the console, including:

- Product Name
- Price
- Category
- Availability Status
- Sold Quantity

This project is created as part of a C# Console Project Assignment.

---

## 🛠 Technologies Used

- C#
- .NET 10.0 SDK
